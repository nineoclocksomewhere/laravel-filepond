## Scope notes

This repository contains a Laravel package with PHP source, one JavaScript client helper, and package routes. It has **no `tests/` directory**, **no CI workflow under `.github/`**, and no HTTP collection, Bruno collection, event listener, queue job, or webhook implementation in the repository at the audited commit. The [testing guide](testing.md) records the resulting validation limits.
